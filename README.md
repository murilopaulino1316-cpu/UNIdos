# UNIdus (React Native / Expo)

    npm install
    npx expo start        # abra no Expo Go (Android/iOS)

- Mapa: `react-native-maps` (Apple Maps no iOS; Google Maps no Android exige chave da API em app.json, ou use development build).
- Dados de demonstração e lógica de busca/distância/entorno vieram do site original (src/data, src/lib).
